# Independent Review Protocol

1. Give the maker the brief, constraints, and source facts.
2. Give a separate reviewer the acceptance criteria and produced artifacts.
3. Keep the maker's confidence claims outside the review packet.
4. Ask the reviewer to identify contradictions and missing evidence.
5. Record each finding with its file and reproduction steps.
6. Let the maker correct confirmed defects.
7. Repeat affected checks after the correction.
8. Report open findings before claiming completion.

This local protocol adapts independent review to video production.
It does not implement the full upstream plugin.
Reference: [Elephant Goldfish Model](https://github.com/google/elephant-goldfish-model).
