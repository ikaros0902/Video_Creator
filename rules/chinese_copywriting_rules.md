# Chinese Copywriting Rules

1. Add a space between Chinese text and Latin letters or digits.
2. Use fullwidth punctuation in Chinese sentences.
3. Use halfwidth Latin letters and digits.
4. Preserve exact code, URLs, and source quotations.
5. Run the copywriting linter before narration synthesis.
6. Report approved exceptions with their source and reason.

Reference: [Chinese copywriting guidelines](https://github.com/sparanoid/chinese-copywriting-guidelines).
